# מספר הסיפורים הטיפולי – גרסה מקומית

בוט שמספר סיפור, שואל שאלות במהלכו ובסופו, ומסכם את המפגש. הגרסה הזו רצה על המחשב שלך: Claude כותב את הסיפורים, ו-ElevenLabs מקריא אותם בקול של כל דמות.

## מה יש בתיקייה

| קובץ | מה הוא עושה |
|---|---|
| `server.js` | שרת קטן שמחזיק את המפתחות ומעביר בקשות ל-Claude ול-ElevenLabs |
| `config.json` | כאן מדביקים את המפתחות ואת מזהי הקולות. **לא משתפים את הקובץ הזה עם אף אחד** |
| `public/index.html` | הדף עצמו |
| `public/img/` | הדמויות |
| `cache/` | הקראות שכבר נוצרו נשמרות כאן, כדי לא לשלם עליהן שוב |

## הפעלה בפעם הראשונה

### 1. לוודא ש-Node.js מותקן
פותחים את **Terminal** ומקלידים:
```
node -v
```
אם מופיע מספר גרסה 18 ומעלה, הכול טוב. אם לא, מורידים את גרסת LTS מ-https://nodejs.org ומתקינים.

### 2. מפתח Anthropic (בשביל סיפורים חדשים)
1. נכנסים ל-https://console.anthropic.com
2. **API Keys** ← **Create Key**
3. מעתיקים את המפתח ומדביקים ב-`config.json` במקום `PASTE_ANTHROPIC_API_KEY_HERE`

בלי המפתח הזה האתר עדיין עובד, אבל רק עם סיפורי הדוגמה.

### 3. מפתח ElevenLabs וקולות
1. נכנסים ל-https://elevenlabs.io ← בתפריט: **Developers** ← **API Keys** ← יוצרים מפתח
2. מדביקים אותו ב-`config.json` במקום `PASTE_ELEVENLABS_API_KEY_HERE`
3. לכל דמות בוחרים קול: **Voices** ← בוחרים קול ← **Copy Voice ID**
4. מדביקים את ה-ID ליד שם הדמות ב-`config.json` (נועה, דני, אבי, מאיה, יואב)

דמות שלא הוגדר לה קול תשתמש בקול העברי של המחשב.

### 4. הפעלה
ב-Terminal:
```
cd ~/Documents/speechBot
node server.js
```
הדפדפן נפתח לבד בכתובת http://localhost:3000.
לעצירה: לוחצים **Ctrl+C** בחלון ה-Terminal.

## שינויים בלי להפעיל מחדש
את `config.json` אפשר לערוך בזמן שהשרת רץ. מספיק לרענן את הדף בדפדפן.

## כמה הערות
- **מודל ההקראה:** ב-`config.json` מוגדר `eleven_v3`, שתומך בעברית. אם ב-ElevenLabs יש מודל חדש יותר שתרצי לנסות, מחליפים את השם בשדה `model`.
- **עלויות:** כל הקראה ב-ElevenLabs וכל סיפור חדש ב-Claude עולים כסף לפי שימוש. סיפור שכבר הוקרא נשמר בתיקייה `cache` ולא נוצר שוב.
- **מהירות דיבור:** ב-ElevenLabs המהירות מוגבלת לטווח 0.7 עד 1.2.
- **הכתבה בקול:** עובדת ב-Chrome וב-Safari. בפעם הראשונה הדפדפן יבקש אישור למיקרופון.
- **קול עברי של המחשב (גיבוי):** ב-Mac: הגדרות מערכת ← נגישות ← תוכן מוקרא ← קול המערכת ← ניהול קולות ← עברית.
- **לפני העלאה לאינטרנט:** השרת הזה מיועד למחשב שלך בלבד. כדי להעלות את האתר לרשת צריך אחסון עם שרת, והמפתחות חייבים להישאר בצד השרת.
